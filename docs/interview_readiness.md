# 面试工程化验收清单

## 已具备

- YOLO11 人物检测、ByteTrack、IdentityManager 和 YOLO11 Pose 流程。
- 行为、穿搭、异常分析结果按视频独立保存。
- SQL Server 导入、Query Engine、FastAPI 和 Vue 前端。
- 事件 Precision/Recall/F1、时间误差和 ID 切换评估脚本。
- 上传、分析任务状态、失败重试、视频播放和结果验收脚本。
- `/health/live` 存活检查和 `/health/ready` 依赖就绪检查。

## 当前边界

- 分析任务仍是单进程、单并发队列，重启后未完成任务需要重试。
- 没有用户认证、权限、配额和多租户隔离，只适合可信内网或本机演示。
- 当前事件评测仍需要人工标注，不能把无标注结果称为准确率。
- 当前异常检测基线为单个已标注视频，不能代表泛化性能。
- SQL Server 和模型依赖本机配置，尚未形成容器化部署方案。

## 建议面试前补齐

1. 准备单人、多人遮挡和异常动作三类固定评测集，保存配置与报告。
2. 增加跨视频汇总脚本，输出 macro/micro Precision、Recall、F1 和性能均值。
3. 为任务队列增加持久化队列或外部 worker；多 worker 部署前禁止共享当前内存状态。
4. 增加认证、上传权限、文件类型校验、大小限制和日志脱敏。
5. 记录请求耗时、任务耗时、失败原因、模型版本和配置版本。
6. 补充部署文档、API 示例、数据库初始化步骤和故障排查流程。

## 推荐展示顺序

```text
视频上传
  -> 异步任务状态
  -> YOLO11/ByteTrack/IdentityManager
  -> Pose/行为/异常/穿搭 JSON
  -> SQL Server
  -> FastAPI 查询
  -> Vue 时间轴与视频定位
  -> Agent 结构化问答
```
